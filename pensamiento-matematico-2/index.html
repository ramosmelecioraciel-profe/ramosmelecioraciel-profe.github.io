    PF1video

    Video: Lenguaje algebraico

    ¿Qué es el álgebra? Es una forma de escribir con letras y símbolos lo que ya sabes decir con palabras. Una letra puede representar un número que no conocemos (incógnita) o que cambia (variable).

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    Lenguaje comúnLenguaje algebraico
    El doble de un número2x
    Un número aumentado en 5x + 5
    La mitad de un númerox/2
    El cuadrado de un número, menos 3x² − 3
    La suma de un número y su consecutivox + (x + 1)

    Para recordar

    • Suma: resultado de sumar. Diferencia: de restar. Producto: de multiplicar. Cociente: de dividir.
    • Residuo: lo que sobra en una división no exacta: 17 ÷ 5 da cociente 3 y residuo 2.
    • Razón: compara dos cantidades dividiendo, como 3/4.
    • Entre número y letra no se escribe el ×: 3 · x se escribe 3x.
    Reto rápido
    1. El triple de un número
    2. Un número disminuido en 7
    3. Si x = 2, ¿cuánto vale 3x + 1?
    4. Residuo de 23 ÷ 4

    Respuestas: 3x · x − 7 · 7 · 3

    PF2video

    Video: Expresiones algebraicas

    Una expresión algebraica está formada por términos separados por + o −. Según cuántos términos tenga, recibe un nombre.

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    EjemploClasificación
    5x²Monomio (1 término)
    3a − 2bBinomio (2 términos)
    x² + 2x + 1Trinomio (3 términos)
    x³ − x² + 4x − 9Polinomio (4 o más)

    Para recordar

    • En −7x³: el coeficiente es −7, la variable es x y el exponente es 3.
    • El grado de un monomio es la suma de los exponentes de sus letras: 4x²y³ es de grado 5.
    • El grado de un polinomio es el mayor grado de sus términos.
    • Si no se ve el coeficiente, vale 1: en x², el coeficiente es 1.
    Reto rápido
    1. ¿Cuántos términos tiene 4x − 1?
    2. Coeficiente de −x⁵
    3. Grado de 2x³y
    4. Perímetro de un cuadrado de lado x

    Respuestas: 2 · −1 · 4 · 4x

    Video: Monomios y binomios

    Con monomios se opera como con números, cuidando los signos y las leyes de los exponentes.

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    EjemploResultado
    3x² + 5x²8x²
    (2x³)(−4x²)−8x⁵
    12x⁵ ÷ 3x²4x³
    2x(3x − 4)6x² − 8x
    6x² + 9x3x(2x + 3)

    Para recordar

    • Solo se suman o restan términos semejantes (misma letra y mismo exponente).
    • Al multiplicar se suman los exponentes; al dividir se restan.
    • Signos: más por más y menos por menos dan más; signos distintos dan menos.
    • Factorizar es lo contrario de multiplicar: se saca el factor común.
    Reto rápido
    1. 4x − 9x
    2. (3x)(5x²)
    3. 10x⁴ ÷ 2x
    4. Factoriza 5x² − 10x

    Respuestas: −5x · 15x³ · 5x³ · 5x(x − 2)

    PF4video

    Video: Trinomios y polinomios

    Para multiplicar polinomios, cada término del primero multiplica a cada término del segundo. Algunos productos son tan comunes que tienen regla: los productos notables.

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    EjemploResultado
    (x + 3)(x + 5)x² + 8x + 15
    (x + 4)²x² + 8x + 16
    (x − 6)²x² − 12x + 36
    (x + 7)(x − 7)x² − 49
    x² + 7x + 12(x + 3)(x + 4)

    Para recordar

    • Binomio al cuadrado: (a + b)² = a² + 2ab + b². ¡No es a² + b²!
    • Binomios conjugados: (a + b)(a − b) = a² − b².
    • Un trinomio cuadrado perfecto se factoriza como binomio al cuadrado: x² + 10x + 25 = (x + 5)².
    • Para factorizar x² + bx + c busca dos números que multiplicados den c y sumados den b.
    Reto rápido
    1. (x + 2)(x + 6)
    2. (x + 1)²
    3. (x + 9)(x − 9)
    4. Factoriza x² − 16

    Respuestas: x² + 8x + 12 · x² + 2x + 1 · x² − 81 · (x + 4)(x − 4)

    Video: Álgebra en la vida diaria

    El álgebra sirve para tomar decisiones con tu dinero, en la cocina o en las compras. Con una letra representas lo que no sabes y planteas una ecuación.

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    EjemploPlanteamiento
    Presupuestoahorro = ingreso − gastos
    Receta para 4 → para 6cantidad × 6/4
    Precio con 25% de descuento0.75x
    Pagaste $450 con 25% de descuento0.75x = 450 → x = $600

    Para recordar

    • Porcentaje significa “de cada cien”: 25% = 0.25.
    • Con descuento d%, pagas (100 − d)% del precio: 30% de descuento → 0.7x.
    • En una proporción directa, si una cantidad se duplica, la otra también.
    • Revisa que tu resultado tenga sentido: un precio con descuento siempre es menor.
    Reto rápido
    1. 15% de $400
    2. Receta para 2 → para 5 (100 g)
    3. $800 con 40% de descuento
    4. Ahorras $250 al mes, ¿meses para $1 500?

    Respuestas: $60 · 250 g · $480 · 6

    Video: Igualdad y ecuación

    Una igualdad dice que dos expresiones valen lo mismo. Si se cumple para cualquier valor de la letra es una identidad; si solo para algunos, es una ecuación.

    El video no tiene narración. Míralo con tu cuaderno abierto y resuelve cada ejemplo antes de que aparezca el resultado; en el reto rápido, pausa y contesta.

    IgualdadPropiedad
    a = aReflexiva
    Si a = b, entonces b = aSimétrica
    Si a = b y b = c, entonces a = cTransitiva
    Si a = b, entonces a + c = b + cUniformidad

    Para recordar

    • Una ecuación es como una balanza: lo que hagas de un lado, hazlo del otro.
    • 3x + 4 = 19 → resta 4: 3x = 15 → divide entre 3: x = 5.
    • Comprueba siempre sustituyendo: 3(5) + 4 = 19 ✔.
    • 2(x + 1) = 2x + 2 es una identidad: se cumple para todo x.
    Reto rápido
    1. x + 8 = 3
    2. 5x = 35
    3. 2x − 1 = 9
    4. ¿Identidad o ecuación? x + x = 2x

    Respuestas: −5 · 7 · 5 · identidad
